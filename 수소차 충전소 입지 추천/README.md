### 2.1 Data Preprocessing and Visualization
본 보고서에서 사용된 모든 데이터들은 Python 및 QGIS 프로그램을 이용하여 전처리를 진행하였다. 

주소로 주어진 데이터(수소차 충전소 현황, 학교 위치정보, 유치원 위치정보, 주유소 위치정보)의 경우 모두 국토교통부의 Geocoder.api를 사용하여 위/경도 값으로 변환 후 포인터로 지도 상에 나타내었다. 행정동별 통계값을 가진 데이터(행정동별 전체 교통량, 주민등록인구통계, 등록 자동차 현황)는 QGIS를 통해 분포를 시각화하였다. 특히 행정동별 등록 자동차 현황은 기존에 공개된 데이터가 없기 때문에 각 행정동의 주민등록인구통계 값과 전체 교통량 통계값을 종속적으로 고려하여 그 값을 산정하였다. 

추가적으로 모델의 입력인 입지 추천의 대상이 되는 공간 정보 데이터는 울산광역시 공간 정보 데이터에서 규제 구역에 해당하는 데이터(학교 위치정보, 유치원 위치정보, 산림입지토양도 공간정보, 낙동강수계/수변구역 공간정보)를 제외시키는 방식으로 확보하였다. 해당 데이터는 25mX25m의 격자로 분할하여 모델의 입력으로 사용하였다.

최종적으로 확보한 통계 데이터들은 모두 후보지 선정에 고려되어야 할 독립변수들이기 때문에 하나의 데이터 프레임으로 통합하고 표준화를 통해 값의 범위를 맞추었다.

### 2.3 Model Input Data Construction
선정된 후보 행정동들의 그리드 데이터 중 **이미 수소차 충전소가 설치된 위치에 해당하는 그리드는 제외**시켰다.

각 그리드들이 위치한 행정동의 인구수, 교통혼잡빈도 강도, 자동차 등록 대수를 고려하도록 특성 값을 구성하였으며 가까운 주유소와의 평균 거리도 추가적인 특성 값으로 고려하였다. 

주유소와의 거리 계산에는 그리드와 모든 주유소 간의 유클리디안 거리를 통하여 구했다. 계산된 거리 값이 가까운 순서대로 정렬하여 가까운 5개 주유소와의 평균 값으로 설정하였다.

최종적으로 <mark>학습 데이터</mark>는 기존 수소차 충전소 설치 위치에 해당하는 그리드 들의 특성 벡터 값을 label 1로, 전체 그리드들 중 기존 위치에 해당하는 그리드들을 제외한 특성 벡터 값을 label 0으로 설정하였다. <mark>예측 데이터</mark>의 경우 후보 행정동에 속하는 유효 그리드들의 특성 벡터 값으로 설정하였다.

## 3. MODEL SETUP
해당 연구를 진행하며 전처리한 데이터들은 모두 벡터값이기 때문에 복잡도가 큰 모델을 사용하는 것보다 비교적 간단한 모델을 사용하는 것이 일반화 측면에 있어 더욱 효과적일 것으로 판단하였다.

### 3.1 Model Architecture
모델은 두 개의 선형 레이어로 이루어져 있고, 활성화 함수에는 ReLU 함수를 사용하여 비선형성을 도입하고 데이터의 특성을 잘 파악할 수 있도록 하였다. 입력 차원은 특성 벡터의 차원으로 설정하였다. 출력 결과를 마지막으로 Sigmoid에 통과시켜 해당 값이 후보지로 선정될 확률을 나타내도록 하였다. 손실 함수는 BCELoss를 사용하였고 Optimizer는 Adam을 사용하였으며 learning rate은 0.0001로 설정하였다.
