# 울산시 수소차 충전소 설치 입지 추천 (2024.10 ~ 2024.11 진행 연구)
---
## 📍 요약
<mark>본 연구는 울산시 내에서 수소차 충전소 설치를 위한 최적의 입지를 도출하는 것을 목표로 한다.</mark> 이를 위해, 울산시가 제공하는 다양한 공공데이터를 활용하여 현재 운영 중인 충전소의 위치 및 공간적 특성을 분석하였다. GIS 기반의 분석 결과를 바탕으로 충전소 설치를 위한 잠재적 후보지를 도출하였으며 <mark>최종적으로 모델을 이용하여 후보 행정동 내의 최적의 입지를 선정하였다.</mark>

특히, 본 연구는 <mark>인구밀도 교통량, 기존 주유소와의 거리, 자동차 등록 대수 등 다양한 평가 요소를 종합적으로 고려</mark>하였다. 이러한 과정을 통해 선정된 최적 입지는 수소차 이용자들의 편의성을 극대화하고, 충전소 이용의 효율성을 높이는 데 기여할 것으로 기대된다. 더 나아가 본 연구는 울산시가 수소 경제를 선도하고 친환경 도시로 발전하는데 중요한 정책적 기초 자료를 제공할 수 있을 것으로 기대된다.

## 1. INTRODUCTION
본 연구는 울산시 내의 다양한 데이터 분석을 통해 앞으로 정부에서 시행할 수소차 보급 확대 사업으로 인한 인프라 부족 문제를 대비하여 최적의 수소차 충전소 입지 추천 알고리즘을 개발하고 최적의 입지를 추천하는 것을 목표로 한다.

해당 보고서는 다음과 같은 구조를 갖는다. 제 2장에서는 데이터 분석 및 분석 결과를 제시하고, 제 3장에서는 모델 구성에 대하여 설명하며, 제 4장에서는 결과를 분석하고, 제 5장에서 결론과 시사점을 논의한다.

## 2. BODY
본 연구를 진행함에 있어 사용한 데이터들의 목록은 다음과 같다.
- 1️⃣ 울산광역시 행정동 경계구역 지도
- 2️⃣ 울산광역시 수소차 충전소 현황
- 3️⃣ 산림입지토양도 공간 정보
- 4️⃣ 낙동강수계/수변구역 공간정보
- 5️⃣ 울산시 학교 위치정보
- 6️⃣ 유치원 위치정보
- 7️⃣ 행정동별 교통혼잡빈도 강도
- 8️⃣ 행정동별 전체 교통량
- 9️⃣ 주민등록인구 통계
- 🔟 울산시 주유소 위치정보
- 1️⃣1️⃣ 행정동별 등록 자동차 현황

### 2.1 Data Preprocessing and Visualization
본 보고서에서 사용된 모든 데이터들은 Python 및 QGIS 프로그램을 이용하여 전처리를 진행하였다. 

주소로 주어진 데이터(수소차 충전소 현황, 학교 위치정보, 유치원 위치정보, 주유소 위치정보)의 경우 모두 국토교통부의 Geocoder.api를 사용하여 위/경도 값으로 변환 후 포인터로 지도 상에 나타내었다. 행정동별 통계값을 가진 데이터(행정동별 전체 교통량, 주민등록인구통계, 등록 자동차 현황)는 QGIS를 통해 분포를 시각화하였다. 특히 행정동별 등록 자동차 현황은 기존에 공개된 데이터가 없기 때문에 각 행정동의 주민등록인구통계 값과 전체 교통량 통계값을 종속적으로 고려하여 그 값을 산정하였다. 

추가적으로 모델의 입력인 입지 추천의 대상이 되는 공간 정보 데이터는 울산광역시 공간 정보 데이터에서 규제 구역에 해당하는 데이터(학교 위치정보, 유치원 위치정보, 산림입지토양도 공간정보, 낙동강수계/수변구역 공간정보)를 제외시키는 방식으로 확보하였다. 해당 데이터는 25mX25m의 격자로 분할하여 모델의 입력으로 사용하였다.

최종적으로 확보한 통계 데이터들은 모두 후보지 선정에 고려되어야 할 독립변수들이기 때문에 하나의 데이터 프레임으로 통합하고 표준화를 통해 값의 범위를 맞추었다.
